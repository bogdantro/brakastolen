{% load static %}{% comment %} Interactive plot picker (tomtevelger) – after the Webiser design prototype, in the site's design. Plots come from the database (Dashboard → Tomter); plot-picker.js builds the list and the map from the JSON at the bottom. The viewing form posts to the normal contact form, so it gets the same spam protection and lands in the dashboard inbox linked to the plot. Parameters: picker_plots and picker_form – from core.views.plot_picker_context(). Brings its own stylesheet and script, so a page only needs to include it. {% endcomment %}
